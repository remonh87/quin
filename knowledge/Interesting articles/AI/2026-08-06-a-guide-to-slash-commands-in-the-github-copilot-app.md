# A guide to slash commands in the GitHub Copilot app

**Date:** 2026-08-06
**URL:** https://github.blog/ai-and-ml/github-copilot/a-guide-to-slash-commands-in-the-github-copilot-app/
**Verdict:** MEDIUM

- **GitHub Copilot app introduces slash commands** as text shortcuts (`/`) in the chat composer to manage sessions, navigate projects, and customize workflows—tailored for the app’s visual interface (unlike CLI commands).

- **Key commands with distinct use cases**:
  - `/plan` – Break down tasks (e.g., features, refactors) before coding.
  - `/spar` – Challenge assumptions/risks (e.g., architecture choices).
  - `/autopilot` – Implement features via goal-driven automation.
  - `/rubber-duck` – Get a second model’s review for blind spots.
  - `/create-canvas` – Turn conversations into interactive workflows.
  - `/orchestrate` – Coordinate multi-repo/multi-task efforts.

- **Workflow integration**: Commands reduce context-switching by replacing UI navigation with typed shortcuts, but require learning and adoption effort.

**Verdict: MEDIUM**
*Relevance is niche—only valuable if already using GitHub Copilot. The guide is thorough but lacks urgency or broad applicability. For a busy developer, the ROI of learning these commands is questionable unless Copilot is central to their workflow.*
