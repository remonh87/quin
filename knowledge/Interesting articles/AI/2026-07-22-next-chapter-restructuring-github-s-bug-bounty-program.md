# Next chapter: Restructuring GitHub’s bug bounty program

**Date:** 2026-07-22
**URL:** https://github.blog/security/next-chapter-restructuring-githubs-bug-bounty-program/
**Verdict:** MEDIUM

### **Key Points:**

- **VIP Program for Top Researchers**: GitHub is launching a private, invite-only program for elite security researchers, offering **higher payouts ($1K–$30K+)** and faster response times. Entry requires **consistent high-quality submissions** (e.g., 1 critical or 7 low-severity bugs).
- **Public Bounty Restructuring**: Static payouts ($250–$10K) replace ranges to **reduce noise** and prioritize quality over quantity. This aims to **filter AI-generated or low-effort reports** while maintaining accessibility for newcomers.
- **Signal Requirement for New Researchers**: A **HackerOne signal threshold** limits initial submissions, ensuring only serious researchers proceed—balancing inclusivity with efficiency.

### **Verdict for Software Developers:**
**MEDIUM** – Relevant only if you engage in security research or use AI tools heavily. The focus on **AI-generated reports** and **quality incentives** is insightful but niche. Most developers can skip this unless directly involved in bug bounties or AI-assisted coding.
